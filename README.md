# partner - Student Helper Chatbot

A friendly, rule-based chatbot built with Python. It chats in a natural way, remembers your name, and responds to feelings, jokes and student questions.

## Features
- Replies with different random responses, so it doesn't repeat itself
- Remembers the user's name during the chat
- Responds kindly when the user feels stressed or sad
- Tells jokes and shares the current time and date
- Gives tips about internships, GitHub and Python
- Types replies letter by letter like a real person

## Technologies Used
- Python 3
- Regular expressions (`re`)
- `random`, `time` and `datetime` modules

## How to Run
1. Install Python 3 from python.org
2. Download `humanized_chatbot.py`
3. Open Command Prompt in the same folder and run:

```
python humanized_chatbot.py
```

## Example
```
partner: Hi! I'm partner. What's your name?
You: Asia
partner: Nice to meet you, Asia!
Asia: tell me a joke
partner: Why do programmers prefer dark mode? Because light attracts bugs!
```
